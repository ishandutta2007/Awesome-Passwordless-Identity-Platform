# Awesome-Passwordless-Identity-Platform

## Top Passwordless Identity Platforms Ecosystem

**Curated List of SaaS Products & Open-Source GitHub Projects**  
*Focused on Passwordless Authentication, Passkeys, WebAuthn/FIDO2, Magic Links, Biometrics & Phishing-Resistant Identity*  
**Last updated: August 2026**

This repository tracks notable **SaaS platforms** and **open-source projects** for **Passwordless Identity**. These tools enable secure, password-free authentication using passkeys, FIDO2/WebAuthn security keys, biometrics, magic links, device-bound credentials, and related modern identity methods for workforce and customer (CIAM) use cases.

**Examples** include HYPR, Beyond Identity, Descope, Stytch, WorkOS, OwnID, Magic, Auth0, Frontegg, FusionAuth, Secret Double Octopus, Trusona, HYPR Authenticate, Microsoft Entra Passwordless, Okta FastPass, Yubico, Cisco Duo, Silverfort, Hanko, Auth0 Passkeys, and Ping Identity (the category leaders).

**Open-source emphasis**: This section is heavily expanded with every major active project for self-hosted passwordless authentication, WebAuthn/passkey servers, identity platforms with FIDO2 support, and open CIAM/IAM solutions — ideal for developers, security teams, and organizations seeking phishing-resistant, standards-based identity without vendor lock-in.

Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## SaaS/Hosted Platforms

- **[HYPR](https://www.hypr.com/)**  
  Enterprise passwordless authentication platform focused on phishing-resistant workforce login using device-bound credentials and FIDO standards.

- **[Beyond Identity](https://www.beyondidentity.com/)**  
  Passwordless identity platform using certificate-based and device-bound credentials for high-assurance workforce and customer authentication.

- **[Descope](https://www.descope.com/)**  
  Developer-friendly CIAM platform with visual flow builder, strong support for passkeys, magic links, and passwordless authentication journeys.

- **[Stytch](https://stytch.com/)**  
  API-first authentication platform specializing in passwordless methods (passkeys, magic links, OTP) for consumer and B2B applications.

- **[WorkOS](https://workos.com/)**  
  Enterprise-ready identity layer for B2B SaaS offering SSO, directory sync, and modern authentication including passkeys.

- **[OwnID](https://www.ownid.com/)**  
  Passwordless authentication solution emphasizing frictionless login experiences with biometrics and device credentials.

- **[Magic](https://magic.link/)**  
  Passwordless authentication platform using magic links and Web3-friendly identity for consumer and developer applications.

- **[Auth0 (Okta Customer Identity)](https://auth0.com/)**  
  Comprehensive identity platform with robust passkey, WebAuthn, and passwordless support alongside traditional authentication methods.

- **[Frontegg](https://frontegg.com/)**  
  Multi-tenant identity and user management platform for SaaS with passwordless options, SSO, and self-service admin portals.

- **[FusionAuth](https://fusionauth.io/)**  
  Flexible authentication and user management platform supporting passkeys, passwordless flows, and self-hosted or cloud deployment.

- **[Secret Double Octopus](https://doubleoctopus.com/)**  
  Passwordless authentication focused on high-security enterprise environments and multi-factor passwordless experiences.

- **[Trusona](https://www.trusona.com/)**  
  Passwordless and multi-factor authentication solutions emphasizing ease of use and strong security for enterprise and consumer use.

- **[Microsoft Entra Passwordless](https://www.microsoft.com/en-us/security/business/identity-access/microsoft-entra-id)**  
  Native passwordless capabilities within Microsoft Entra ID, including Windows Hello, FIDO2 keys, and passkeys.

- **[Okta FastPass](https://www.okta.com/)**  
  Okta’s passwordless authentication feature providing phishing-resistant login across devices and applications.

- **[Yubico](https://www.yubico.com/)**  
  Hardware security key provider (YubiKeys) and supporting software for FIDO2/WebAuthn passwordless authentication.

- **[Cisco Duo](https://duo.com/)**  
  Multi-factor and passwordless authentication platform with strong device trust and adaptive access controls.

- **[Silverfort](https://www.silverfort.com/)**  
  Unified identity protection platform extending passwordless and MFA to legacy and modern systems.

- **[Hanko (Cloud)](https://www.hanko.io/)**  
  Modern authentication platform (also available open-source) focused on passkeys and passwordless user experiences.

- **[Ping Identity](https://www.pingidentity.com/)**  
  Enterprise identity platform with advanced passwordless, passkey, and adaptive authentication capabilities.

## Open-Source GitHub Projects

- **[Hanko](https://github.com/teamhanko/hanko)**  
  Open-source, passkey-first authentication and user management platform — a modern alternative to Auth0, Clerk, Stytch, and WorkOS with WebAuthn, magic links, and SSO support.

- **[Keycloak](https://github.com/keycloak/keycloak)**  
  Leading open-source identity and access management solution with strong WebAuthn/passkey support, MFA, SSO, and extensive federation capabilities.

- **[Authelia](https://github.com/authelia/authelia)**  
  Open-source authentication and authorization server providing SSO, MFA, and passwordless WebAuthn/passkeys as a companion to reverse proxies.

- **[SuperTokens](https://github.com/supertokens)**  
  Open-source authentication platform offering passwordless (OTP/magic links), session management, social login, and self-hosted or managed options.

- **[Zitadel](https://github.com/zitadel/zitadel)**  
  Modern open-source identity platform with strong passkey/WebAuthn support, multi-tenancy, and API-first design.

- **[Ory Kratos](https://github.com/ory/kratos)**  
  Headless, API-first open-source identity management system supporting passwordless flows, passkeys, and customizable authentication.

- **[Authentik](https://github.com/goauthentik/authentik)**  
  Flexible open-source identity provider with support for passkeys, MFA, SSO, and extensive flow customization.

- **[privacyIDEA](https://github.com/privacyidea/privacyidea)**  
  Open-source multi-factor authentication server specializing in OTP, tokens, and passwordless authentication methods.

- **[WebAuthn Libraries (passwordless-id, go-webauthn, etc.)](https://github.com/passwordless-id/webauthn)**  
  Open-source client and server libraries that simplify implementing WebAuthn and passkeys in custom applications.

- **[SimpleWebAuthn](https://github.com/MasterKale/SimpleWebAuthn)**  
  Popular open-source TypeScript/JavaScript libraries for easily adding WebAuthn/passkey support to web applications.

- **[Authgear](https://github.com/authgear/authgear-server)**  
  Open-source Auth0/Clerk alternative supporting passkeys, passwordless, biometrics, SSO, and self-hosted deployment.

- **[Casdoor](https://github.com/casdoor/casdoor)**  
  Open-source UI-first Identity and Access Management (IAM) / Single-Sign-On (SSO) platform with WebAuthn support.

### Additional Strong Open-Source Options

- **Identity platforms**: Gluu, FreeIPA, and other mature open IAM solutions with FIDO2 capabilities.
- **WebAuthn/FIDO libraries**: Language-specific servers and clients for Go, Python, Java, .NET, and JavaScript.
- **Passkey-focused tools**: Community passkey demo servers, credential managers, and testing harnesses.
- **Reverse-proxy auth**: Additional Authelia-style gateways and oauth2-proxy variants with passwordless support.
- Many experimental and production **passkey-only** authentication services and SDKs on GitHub.

**Frameworks for building custom systems**: Combine **Hanko** or **Keycloak** as the core identity provider, **WebAuthn libraries** for native passkey support, **Authelia** for SSO gateway protection of internal apps, and open session/JWT tools to create a complete self-hosted passwordless identity platform.
