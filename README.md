## 🌟 Top Passwordless Identity Platforms Ecosystem

**Curated List of SaaS Products & Open-Source GitHub Projects**  
*Focused on Passwordless Authentication, Passkeys, WebAuthn/FIDO2, Magic Links, Biometrics & Phishing-Resistant Identity*  
**Last updated: August 2026**

This repository tracks notable **SaaS platforms** and **open-source projects** for **Passwordless Identity**. These tools enable secure, password-free authentication using passkeys, FIDO2/WebAuthn security keys, biometrics, magic links, device-bound credentials, and related modern identity methods for workforce and customer (CIAM) use cases.

**Examples** include HYPR, Beyond Identity, Descope, Stytch, WorkOS, OwnID, Magic, Auth0, Frontegg, FusionAuth, Secret Double Octopus, Trusona, HYPR Authenticate, Microsoft Entra Passwordless, Okta FastPass, Yubico, Cisco Duo, Silverfort, Hanko, Auth0 Passkeys, and Ping Identity (the category leaders).

**Open-source emphasis**: This section is heavily expanded with every major active project for self-hosted passwordless authentication, WebAuthn/passkey servers, identity platforms with FIDO2 support, and open CIAM/IAM solutions — ideal for developers, security teams, and organizations seeking phishing-resistant, standards-based identity without vendor lock-in.

Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

- **[Keycloak](https://github.com/keycloak/keycloak)** [![GitHub stars](https://img.shields.io/github/stars/keycloak/keycloak?style=social&color=white)](https://github.com/keycloak/keycloak/stargazers)

### Additional Strong Open-Source Options

- **Identity platforms**: Gluu, FreeIPA, and other mature open IAM solutions with FIDO2 capabilities.
- **WebAuthn/FIDO libraries**: Language-specific servers and clients for Go, Python, Java, .NET, and JavaScript.
- **Passkey-focused tools**: Community passkey demo servers, credential managers, and testing harnesses.
- **Reverse-proxy auth**: Additional Authelia-style gateways and oauth2-proxy variants with passwordless support.
- Many experimental and production **passkey-only** authentication services and SDKs on GitHub.

**Frameworks for building custom systems**: Combine **Hanko** or **Keycloak** as the core identity provider, **WebAuthn libraries** for native passkey support, **Authelia** for SSO gateway protection of internal apps, and open session/JWT tools to create a complete self-hosted passwordless identity platform.
